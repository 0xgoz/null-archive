Welcome to 0xgoz.xyz - Linux, security tooling and homelab automation.

I build terminal UIs for the tools I use every day: network recon, DNS, and hypervisor management. Mostly Rust and Ratatui, some Python. Keyboard-driven, no mouse required, no browser tab left open.

Off the keyboard it's self-hosted infrastructure, Proxmox clusters, and breaking things on purpose to learn how they hold together.

This site is built with Three.js, featuring dynamic particle systems, geometric shapes, and retro terminal aesthetics.
